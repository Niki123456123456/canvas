# Image & Vector Canvas Composer

A lightweight canvas-based tool for **combining multiple images and vector graphics into a single composition**. Customize the background color and export your final design as **PNG or JPG**.

This project provides a simple interface for arranging graphical elements on a canvas and exporting the final result as a static image.

---

## Features

### 🖼 Import Multiple Images
Add and position multiple raster images on the canvas.

### 🔷 Vector Graphics Support
Load and merge vector graphics alongside raster images.

### 🎨 Custom Background
Change the canvas background color dynamically.

### 📐 Canvas Layout
Freely arrange elements on the canvas.

### 💾 Export
Export the final composition as:

- PNG
- JPG

### ⚡ Client-Side Rendering
All rendering and exporting happens directly in the browser.
